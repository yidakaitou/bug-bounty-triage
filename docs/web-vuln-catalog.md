# Web 通用漏洞目录（统一版）

> 用途：作为 agent 的检查清单，也是提交前的自检表。
> 每条都带**证伪条件**——命中信号只代表"值得验证"，过了证伪才算数。
> 定级参考按国内公益 SRC 平台的常见口径，实际以审核为准。

---

## 〇、通用检测流程

```
1. 资产与指纹     域名/子域/端口 → 中间件/框架/版本/CMS
2. 入口枚举       登录、注册、上传、搜索、导出、API、回调
3. 逐类探测       按下面的目录，从"低风险高收益"往下打
4. 证据固定       原始请求 + 原始响应 + 时间戳 + 复现命令
5. 证伪           先想"这可能不是漏洞"的三种解释，逐一排除
6. 定级与报告     影响面 × 利用难度 × 是否需要前置条件
```

**顺序原则**：无破坏性 → 低风险 → 高风险。**任何一步发现能证明问题，立即停手留证。**

## 一、认证与授权

### 1.1 越权（IDOR / BOLA）

| | |
|---|---|
| **原理** | 接口只校验"登录了"，不校验"这个资源是不是你的" |
| **探测特征** | URL/body 里有 id、uid、orderId、uuid；响应含他人信息 |
| **验证** | 两个账号 A/B，A 建资源取 ID，B 用该 ID 请求 |
| **证伪** | ① 两 ID 同属一人 ② 返回 200 但内容为空/脱敏 ③ 前端过滤了但后端也拦了 |
| **定级** | 同租户=中危；跨租户/可批量=高危 |

### 1.2 未授权访问

| | |
|---|---|
| **原理** | 接口/页面根本没做鉴权 |
| **探测特征** | 直接访问后台路径、API 返回数据、免登录进管理页 |
| **验证** | 不带 Cookie 请求一次 |
| **证伪** | 返回登录页/401/403；或返回的是公开数据 |
| **定级** | 敏感功能=高危；公开数据=不成立 |

### 1.3 弱口令 / 默认口令

| | |
|---|---|
| **原理** | 出厂默认或弱密码未改 |
| **探测特征** | 登录框无验证码、无锁定、产品已知默认值 |
| **验证** | **单次**尝试产品文档标注的默认口令（不做字典） |
| **证伪** | 有验证码/锁定/二次验证；或账号需邀请 |
| **定级** | 中高危（能进后台）|

> **合规红线**：只做默认口令验证，不做字典爆破。爆破在多数平台属于违规。

### 1.4 JWT / 会话缺陷

| | |
|---|---|
| **原理** | 签名可绕、密钥弱、alg 可改、无过期 |
| **探测特征** | Authorization: Bearer eyJ...；发现 `alg` 字段 |
| **验证** | ① 改 alg 为 none ② 改 payload 的 sub/role ③ 观察是否仍通过 |
| **证伪** | 服务端拒绝并返回 401 |
| **定级** | 高（可伪造任意身份）|

## 二、注入类

### 2.1 SQL 注入

| | |
|---|---|
| **原理** | 用户输入拼接进 SQL |
| **探测特征** | 数字/字符串参数、排序、筛选、导出、报表 |
| **验证** | ① `'` 看报错 ② `and 1=1` vs `and 1=2` 看响应差异 ③ 时间盲注：`sleep(3)` **三次**测方差 |
| **证伪** | 三次延迟方差 >35%（网络抖动）；布尔差异来自缓存；参数被强转 int |
| **定级** | 中高危（能拖库=高危）|

### 2.2 命令注入

| | |
|---|---|
| **原理** | 输入拼进 shell |
| **探测特征** | ping/traceroute/图片处理/压缩/PDF 生成/备份 |
| **验证** | `;sleep 5`、`|sleep 5`、`$(sleep 5)`，三次测时间差 |
| **证伪** | 延迟不稳定；或参数被白名单过滤 |
| **定级** | 高危/严重 |

### 2.3 模板注入（SSTI）

| | |
|---|---|
| **原理** | 用户输入被当模板渲染 |
| **探测特征** | 回显"你的名字是 {name}"这类；报错含模板引擎名 |
| **验证** | 提交 `{{7*7}}`、`${7*7}`、`<%=7*7%>`，看是否回显 49 |
| **证伪** | 原样输出（说明未渲染）；或已转义 |
| **定级** | 高危（常可 RCE）|

### 2.4 XXE

| | |
|---|---|
| **原理** | XML 解析器允许外部实体 |
| **探测特征** | 接口接受 XML；SOAP；文件导入 |
| **验证** | 提交含 `<!ENTITY>` 的最小 XML，看是否回显本地文件 |
| **证伪** | 解析器已禁用外部实体；返回格式错误 |
| **定级** | 中高危 |

### 2.5 CRLF / 头注入

| | |
|---|---|
| **原理** | 输入进入响应头，可注入换行 |
| **探测特征** | 跳转参数、语言/主题切换、文件名回显 |
| **验证** | 参数里插 `%0d%0aX-Test: 1`，看响应头是否出现 |
| **证伪** | 头未出现；或被过滤 |
| **定级** | 中危（可配合缓存投毒/XSS）|

## 三、文件类

### 3.1 路径穿越 / 任意文件读取

| | |
|---|---|
| **原理** | 文件名拼接路径未过滤 `../` |
| **探测特征** | download?file=、read?path=、模板、日志查看、语言包 |
| **验证** | `../../etc/passwd`（Linux）/ `..\..\windows\win.ini` |
| **证伪** | 返回 404/403；或读到的内容不像目标文件 |
| **定级** | 中危；读到配置文件（含密钥）=高危 |

### 3.2 任意文件上传

| | |
|---|---|
| **原理** | 只校验前端或后缀黑名单 |
| **探测特征** | 头像、附件、导入、证件 |
| **验证** | ① 双后缀 `.php.jpg` ② 改 Content-Type ③ 改文件头 |
| **证伪** | 落到对象存储且强制 attachment；或被重命名为随机无后缀 |
| **定级** | 高危（能解析=严重）|

### 3.3 文件包含（LFI）

| | |
|---|---|
| **原理** | 参数直接进 include |
| **探测特征** | ?page=、?lang=、?tpl= |
| **验证** | 指向已知文件，看是否被包含执行/输出 |
| **证伪** | 白名单限定；或只输出空 |
| **定级** | 高危 |

## 四、客户端类

### 4.1 XSS

| | |
|---|---|
| **原理** | 输入未编码输出到 HTML/JS |
| **探测特征** | 搜索回显、昵称、评论、URL 参数回显 |
| **验证** | `<script>alert(1)</script>`、`"><img src=x onerror=1>` |
| **证伪** | 被转义；被 CSP 拦截；只在自己浏览器里弹 |
| **定级** | 反射=低危；存储=中危；管理员可见=高危 |

### 4.2 CSRF

| | |
|---|---|
| **原理** | 敏感操作无 token 校验 |
| **探测特征** | 改密码/绑定手机/转账的表单无 token |
| **验证** | 构造跨站表单，看是否生效 |
| **证伪** | 有 SameSite=Lax/Strict；有 token；校验 Referer |
| **定级** | 中危 |

### 4.3 CORS 配置错误

| | |
|---|---|
| **原理** | `Access-Control-Allow-Origin` 反射任意源 + `Allow-Credentials: true` |
| **探测特征** | 响应头含 ACAO |
| **验证** | 发 `Origin: https://evil.com`，看是否回显 |
| **证伪** | 只允许白名单源；或无 credentials |
| **定级** | 中危 |

### 4.4 点击劫持

| | |
|---|---|
| **原理** | 缺 `X-Frame-Options` / `frame-ancestors` |
| **验证** | 用 iframe 嵌入，看是否被渲染 |
| **证伪** | 有 XFO 或 CSP frame-ancestors |
| **定级** | 低危（多数平台不收）|

## 五、服务端请求类

### 5.1 SSRF

| | |
|---|---|
| **原理** | 服务端代你发请求，未限制目标 |
| **探测特征** | 图片抓取、webhook、URL 预览、PDF 导出、代理 |
| **验证** | 指向 127.0.0.1 的内网端口，看响应差异 |
| **证伪** | 只做 302 未实际请求；有域名白名单；返回固定错误页 |
| **定级** | 中危；打到元数据（169.254.169.254）=高危 |

### 5.2 开放重定向

| | |
|---|---|
| **原理** | 跳转参数未校验域名 |
| **验证** | `?next=https://evil.com`，看是否 302 过去 |
| **证伪** | 只允许相对路径；或跳转前有确认页 |
| **定级** | 低危（常被拒）|

## 六、业务逻辑

### 6.1 价格/数量篡改

| | |
|---|---|
| **原理** | 服务端信任前端传的金额或数量 |
| **验证** | `quantity=-1`、`price=0.01`、`total=0` |
| **证伪** | 服务端重算；或下单失败 |
| **定级** | 中高危 |

### 6.2 竞态条件

| | |
|---|---|
| **原理** | 检查与写入之间有窗口 |
| **探测特征** | 兑换、提现、领券、库存、邀请奖励 |
| **验证** | 并发 20 个相同请求（**带同一个 token**） |
| **证伪** | 只有响应 200，但余额/库存没变 |
| **定级** | 高危（能重复获利）|

### 6.3 验证码/短信绕过

| | |
|---|---|
| **原理** | 验证码可复用、可爆破、可前端校验 |
| **验证** | ① 同码复用 ② 响应包改结果 ③ 删除验证码参数 |
| **证伪** | 服务端强校验 + 一次性 |
| **定级** | 中危；导致任意注册=高危 |

### 6.4 支付回调伪造

| | |
|---|---|
| **原理** | 回调未验签，或签名可预测 |
| **验证** | 重放/篡改回调参数，看订单状态是否变 |
| **证伪** | 验签失败 |
| **定级** | 高危 |

## 七、信息泄露

| 类型 | 探测路径 | 定级 |
|---|---|---|
| 源码/备份 | `/www.zip`、`/backup.rar`、`/index.php.bak` | 中危 |
| 版本控制 | `/.git/config`、`/.svn/entries` | 中危 |
| 接口文档 | `/swagger-ui.html`、`/v2/api-docs`、`/doc.html` | 低中危 |
| 监控端点 | `/actuator/env`、`/actuator/heapdump` | 高危 |
| 错误详情 | 触发 500，看是否含路径/SQL | 低危 |
| 目录列表 | 访问无 index 的目录 | 低危 |
| 云存储 | OSS/S3 桶可列、可写 | 中高危 |
| 内部地址 | 响应头/跳转泄露内网 IP | 低危 |

**证伪**：返回 403（WAF 拦截）≠ 泄露；返回 404 页含关键词 ≠ 泄露。

## 八、传输与中间件

| 类型 | 原理 | 验证 |
|---|---|---|
| HTTP 请求走私 | 前后端解析差异 | CL.TE / TE.CL 探针 |
| 缓存投毒 | 缓存键不含关键头 | 投毒后换 IP 访问 |
| Host 头注入 | 信任 Host | 改 Host 看是否影响跳转/链接 |
| 不安全的 TLS | 证书过期/弱套件 | 直接访问看告警 |

## 九、组件与框架

**这一类是传统站的主要出路。**

| 组件 | 特征 | 已知问题 |
|---|---|---|
| Struts2 | `.action`、`struts` 报错 | OGNL 注入 → RCE |
| ThinkPHP | `?s=`、`/index.php/` 路由 | 多处 RCE |
| Shiro | `rememberMe=` Cookie | 反序列化 RCE |
| Fastjson | JSON 请求体 | autoType 反序列化 |
| Log4j | 任何记录日志的输入 | JNDI 注入 |
| WebLogic | `:7001`、`/console` | 多个反序列化 |
| Spring | `/actuator/*` | 配置泄露、SpEL |
| 织梦/帝国/PHPCMS | 后台路径固定 | 大量历史漏洞 |
| UEditor | `/ueditor/` | SSRF、任意上传 |

**验证**：先指纹，再查对应版本。**不要盲打 PoC**——盲打会打崩服务。

## 十、API 专项

### 10.1 GraphQL

| | |
|---|---|
| **内省** | `{__schema{types{name}}}`——能回就是没关 |
| **字段级越权** | 拿自己数据，看返回里有无他人字段 |
| **隐藏 mutation** | 内省里列出但前端未使用的操作 |
| **批量查询** | 单请求多查询绕过限流 |

### 10.2 REST 未授权 / Mass Assignment

| | |
|---|---|
| **未授权** | 去掉 token 重放 |
| **Mass Assignment** | 在 body 里加 `"role":"admin"`、`"isVip":true`，看是否被接受 |

## 十一、提交前自检

| 检查项 | 通过标准 |
|---|---|
| 有原始请求和响应吗 | 有，且能重放 |
| 有对照组吗 | 有（注入类必须有） |
| 证伪条件排除了吗 | 逐条写过 |
| 影响面写清了吗 | 能说"影响 X 条什么数据" |
| 是目标单位资产吗 | 有备案/版权/证书证明 |
| 在授权范围内吗 | scope 明确 |
| 报告是 AI 腔吗 | 重写过 |

## 十二、不做的清单

- 爆破、字典、撞库
- DoS、压测、无限并发
- 上传 webshell
- 下载/存储真实用户数据
- 打第三方托管（云厂商、SaaS、CDN）
- 破坏数据、留后门
- 对同一目标批量提交同类变体
